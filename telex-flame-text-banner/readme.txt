A striking banner block that renders text with animated flame effects rising from the letters.

== Description ==

The Flame Text Banner Block lets you create eye-catching banners with animated fire effects on your text. Flames dance and flicker realistically above each letter, creating a dramatic visual impact perfect for headlines, call-to-action sections, or any content that needs to stand out.

**Features:**

* Fully customizable banner text
* Animated flame particles that rise from each letter
* Configurable flame color scheme (inner and outer flame colors)
* Adjustable text size (small, medium, large, extra-large)
* Dark background with customizable overlay
* Smooth, performant CSS and canvas-based animation
* Responsive design that works on all screen sizes
* Live preview in the block editor

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/telex-flame-text-banner` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. In the block editor, search for "Flame Text Banner" and insert it into your content.
4. Type your desired text and customize the flame appearance using the block sidebar controls.

== Frequently Asked Questions ==

= Can I change the flame colors? =

Yes! Use the block sidebar controls to set both the inner (bright) and outer flame colors for a custom fire look.

= Does this affect page performance? =

The animation uses an efficient canvas-based particle system that pauses when the block is not visible on screen, ensuring minimal performance impact.

= Can I adjust the text size? =

Yes, you can choose from four text size presets: Small, Medium, Large, and Extra Large.
